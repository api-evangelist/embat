# Embat

> Embat is a real-time treasury management platform for finance teams. Its REST/JSON API connects third-party applications to Embat to manage bank connections, balances, transactions, payments, cash-flow forecasting, accounting entries, and reconciliation across multiple companies. Organized around REST principles with HTTP Bearer (JWT) authentication.

Auth: obtain a JWT `idToken` via `POST /authentication/token` (email/password); send it as `Authorization: Bearer <idToken>`. Tokens expire after 60 minutes; there is no refresh endpoint. All resources are scoped by a `companyId` path parameter. List endpoints paginate with `limit` + `nextPageToken`. Sandbox testing requires requesting sandbox credentials (tech@embat.io).
